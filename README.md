# АНО «Среда возможностей» — Тестовое задание Frontend

Лендинг для системы регулярной оценки корпоративных компетенций.

## Стек

- **Vite** — сборка
- **Vanilla JS** — без фреймворков
- **SCSS + BEM** — стилизация с методологией BEM и `&`-нестингом
- **Swiper** — слайдер на мобайле

## Структура

```
src/
├── assets/
│   ├── fonts/       # Century Gothic (woff, woff2)
│   ├── icons/       # SVG иконки
│   ├── images/      # PNG изображения
│   └── video/       # Видео для модального окна
├── Components/
│   └── UI/
│       ├── Banner/           # Главный блок с заголовком и карточками правил
│       ├── NavTabs/          # Навигационные табы
│       ├── AssessmentCards/  # Карточки оценок
│       ├── Webinar/          # Блок вебинара с видеоплеером
│       ├── ProcessRules/     # Блок правил (Swiper на мобайле)
│       ├── Modal/            # Модальное окно с видео
│       ├── PlayButton/       # Кнопка воспроизведения
│       ├── InfoCard/         # Карточка с иконкой и текстом
│       └── Buttons/          # ButtonPrimary, ButtonSecondary, Tab
├── main.js          # Точка входа
├── main.scss        # Глобальные стили, CSS-переменные, .container
└── normalize.scss   # CSS reset
```

## Запуск

```bash
npm install
npm run dev
```

## Особенности реализации

- Каждый компонент — самостоятельная папка с `.js` + `.scss`
- CSS-переменные для всех цветов и переходов
- Адаптивная типографика через `clamp()` (393px → 1920px)
- Grid-first подход, Flexbox для выравнивания
- Модальное окно с видео: открывается по клику на PlayButton, закрывается по клику на оверлей, крестику или `Escape`
- ProcessRules: 4-колоночный грид на десктопе, Swiper слайдер на мобайле (≤ 400px)
- AssessmentCards: адаптив с иконками на планшете и мобайле
